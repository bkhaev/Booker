Структура проекта:
- index.html: Страница поиска
- index.js: логика и инициализация приложения
- index.css: стили
- api: АПИ
  - index.php: Обработка HTTP-запросов
  - .htaccess: настройка конфигурации URL адреса
- service:
  - bookerlib.php: библиотека функций
  - config.php: скрипт подключения к БД
  - update_db.php: скрипт парсинга

Руководство пользователя
Для поиска по ключевым словам использовать поле ввода
Сузить круг можно с помощью выбора авторов и жанров в фильтрах.
Чтобы открыть фильтры, нажать на кнопку "Показать фильтры".
Результаты поиска обновляются после:
- нажатия на кнопку "Искать"
- ввода ключевых слов (нажать на Enter / нажать вне поля ввода)
- изменения фильтров (добавить / убрать автора)

Особенности сайта:
- нет описания книг, берётся рандомный текст из функции в update_db.php.
- Могут быть книги без автора.
- Жанр всегда один
